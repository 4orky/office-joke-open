# Office Joke Open — one-line entry

[![make.fun entry badge][badge-entry]][bounty-link]
[![make.fun rank badge][badge-rank]][leaderboard-link]
[![make.fun reward badge][badge-reward]][bounty-link]

This repository holds one joke about office life, no longer than two
hundred characters, written for the make.fun Office Joke Open. The
script drafts a dozen original one-liners, grades them on setup,
twist, detail, novelty and economy, and writes the winning line to
`/output/entry.txt`. Here is the line it picked:

> "I asked for a raise and my manager gave me a standing desk instead, so now I can worry about money on my feet."

## How to run it

Run `python3 main.py` from this directory, then read the entry file
it writes.

## How the winner was picked

Twelve original drafts were graded on five craft axes, with the twist
counted double because the laugh lives or dies on the turn. The
highest weighted total won, with ties broken by the shorter text. The
draft above won because it pairs a familiar ask with a concrete office
object, then turns the whole thing around in its last few words.

Built for the Office Joke Open on [make.fun][bounty-link].
